# n8n-learning-lab

Учебная песочница: тренируюсь собирать автоматизации в n8n.
Это не коммерческий проект и не портфолио услуг — просто место, где я учусь и складываю рабочие сценарии.

## Стек

- n8n 2.44.6 (локально, через `npx`)
- Node.js 24.22.1
- DeepSeek API (`deepseek-flash`)
- ntfy.sh — пуш-уведомления
- wttr.in — погода без API-ключа

## Workflows

| Файл | Что делает |
|---|---|
| `weather-ntfy.json` | Каждый день в 9:00 берёт погоду в Екатеринбурге и присылает уведомление в ntfy |

## Как запустить

1. Установить Node.js 24+.
2. В папке с проектом выполнить `npx.cmd n8n` (или двойной клик по `start-n8n.cmd`).
3. Открыть http://localhost:5678.
4. Импортировать `weather-ntfy.json`.
5. Создать нужные credentials в n8n (ключи в репозиторий не попадают).

## Заметки о доступности сервисов

- Telegram Bot API недоступен из домашней сети (проверено 26.10.2026, TCP 443 не открывается). Уведомления идут через ntfy.sh. При появлении VPN можно вернуться к Telegram.
- `api.open-meteo.com` тоже недоступен, поэтому погода берётся с `wttr.in`.
